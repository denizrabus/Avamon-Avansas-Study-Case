# Claude Guidelines

This repository uses `AGENTS.md` as the canonical AI working agreement.

Before making changes, read and follow:

- `AGENTS.md`
- `README.md`
- `docs/ai/AI_USAGE.md`
- `docs/ai/DECISIONS.md`
- `docs/ai/AI_PIPELINE.md`
- `docs/TESTING.md`

## Working Rules

- Keep user-facing product copy in English.
- Keep explanations and handoff notes clear enough for team review.
- Do not introduce new dependencies unless the trade-off is documented.
- Keep changes scoped to the requested behavior.
- Prefer existing project patterns over new abstractions.
- Run the relevant checks after changes and report any failures.
